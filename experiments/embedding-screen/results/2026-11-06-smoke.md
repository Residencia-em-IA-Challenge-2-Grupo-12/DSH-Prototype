Measurements use one CPU thread and a 4,096 MiB per-process virtual address-space cap, not a container RSS limit. Results use the same Python 3.13.16, CPU PyTorch 2.15.0, Transformers 5.22.2 and Sentence Transformers 6.2.0 environment. Gemma ran separately after installing Pillow and CPU torchvision and staging its chat template; runs shared machine caches and were not controlled performance trials. No precision/quality or cross-model speed conclusions follow from these figures.

The JSON records source revisions via the staged revision files, SHA-256 hashes, model file manifests, per-query rankings, metrics and run configuration. Some model snapshots include non-text weights even when only text inference is used. They were downloaded to a temporary location; no model weights are committed.
