# Contexto fictício da pessoa estudante

Ana é uma estudante universitária adulta com trabalho de meio período. Ela quer um plano viável para um projeto de análise de dados, preservando tempo para descanso e deslocamento. Prefere blocos curtos e quer revisar o plano antes de qualquer alteração na agenda.

As janelas de estudo são possibilidades, não reservas. Confira os compromissos e pergunte antes de criar eventos.
