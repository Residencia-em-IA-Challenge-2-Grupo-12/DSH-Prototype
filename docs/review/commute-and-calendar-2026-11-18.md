## Behavior and options

The calendar renderer gives overlapping timed events separate lanes. The planner uses authored study windows and avoids opaque busy events, while transparent or cancelled events do not consume capacity. Changing a busy commute to transparent would also free that time for ordinary focused study. This is too broad for the participant's requested exception.

For an initial experiment in #43, present an optional activity attached to an explicitly selected passenger commute, with no extra calendar write. Keep the primary study target intact, allow skipping without a missed-session penalty, and count reported minutes only once. Test against a work shift, an unknown travel mode and a second unrelated busy commitment in the same interval. If users need a separate reminder or calendar entry, compare a linked optional event with its own approval, move/cancel behavior and provider checks. Both are proposed designs.
